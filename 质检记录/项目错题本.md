# 键盘锁定项目错题本

## QC-INPUT-001 笔记本功能键未完全屏蔽

- 编号：QC-INPUT-001
- 问题分类：输入拦截 / 功能键 / 远程连接连续性
- 实际错误：程序能阻止普通物理键盘输入，但联想笔记本的 `F8`（必要时为 `Fn+F8`）飞行模式动作仍可能绕过普通键盘钩子；猫误触飞行模式可能导致远程连接中断。
- 正确结果：保护开启后，标准音量、静音、亮度、媒体、无线/飞行模式、电源和睡眠功能键应尽量被吞掉；远程普通键盘输入继续可用。
- 根本原因：原实现只依赖普通低级键盘钩子，未单独覆盖 `VK_F8`、系统热键和厂商 EC/服务路径，也没有按功能键类别做真实硬件验收。
- 预防规则：功能键按类别建立清单；保护开启时同时启用低级键盘钩子、`RegisterHotKey(VK_F8)` 与 WLAN 无线电状态监视/恢复；对硬件层强制关闭而无法从普通用户态恢复的厂商专用键明确标注风险，不把代码自检当作真实硬件通过。
- 生成前检查：核对功能键类别、虚拟键映射、系统级占用是否可注册、远程输入是否仍需放行；锁定前确认解锁和退出路径。
- 生成后验证：保护开启后真实按下 `F8`/`Fn+F8`，确认 WLAN 和远程连接持续；同时实按音量、静音、亮度、媒体、电源/睡眠键并从远程端输入文字；分别记录标准键通过、无线电 API 恢复结果与厂商专用键未覆盖。
- 适用范围：本项目所有键盘保护版本。
- 来源：用户反馈（2026-09-25 首次反馈，2026-09-26 明确为 `F8` 且再次反馈未屏蔽）。
