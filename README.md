# 猫咪键盘守护

这是一个无第三方依赖的 Windows 小工具，用于阻止猫误触本机物理键盘，同时保留远程连接工作。程序不会锁定 Windows 会话。
键盘保护开启时，除字母、数字和普通组合键外，还会拦截标准的音量、静音、亮度、媒体播放、无线/飞行模式、`F8`、电源和睡眠功能键。对联想等厂商可能绕过 Windows 键盘层的飞行模式键，程序还会在保护期间通过 WLAN API 周期性检查并尝试恢复软件无线电。

## 启动

双击 `CatKeyboardGuard.exe`。程序启动后会显示主窗口，关闭主窗口后仍会在系统托盘运行。`Start-CatKeyboardGuard.vbs` 保留为兼容入口。
主窗口为 `240 x 220` 的紧凑半透明窗口，可按住猫头、标题或状态文字拖动；右上角关闭按钮仅将它收到系统托盘。
键盘保护开启后的解锁悬浮层为 `238 x 112` 无边框窗口，背景完全透明，只显示猫头、状态、进度条和长按解锁按钮。可拖动猫头或标题改变位置。

## 远程输入兼容

- Microsoft RDP 会话中的输入会直接放行。
- ToDesk、AnyDesk、向日葵等共享桌面软件，如果为键盘事件添加了 Windows “注入输入”标记，也会被放行。
- 鼠标始终保留，所以即使某款远程软件的键盘模式不兼容，仍可以用远程鼠标长按悬浮窗解锁。

不同远程软件的输入实现不同。正式离开前，请开启保护，再从远程端打开记事本输入几个字，确认远程键盘可用，并在本机实按一次 `F8`（必要时为 `Fn+F8`）确认 WLAN 没有断开。少数笔记本厂商把飞行模式键放在独立 EC/厂商服务层处理；这类硬件状态如果被固件强制关闭，普通用户程序可能无法恢复，不能把代码自检当成真实硬件通过。

## 解锁方式

1. 用鼠标在悬浮窗中长按“按住解锁” 3 秒。
2. 同时长按 `Ctrl+Alt+U` 2 秒。
3. 如果主动开启了自动解锁，等待设定的时间。该选项默认关闭。
4. 紧急时按 `Ctrl+Alt+Delete`，进入 Windows 安全界面后可用鼠标注销。

## 设计边界

这是防误触工具，不是安全边界。它不拦截 `Ctrl+Alt+Delete`，也不会保护未锁定的 Windows 会话。某些使用驱动模拟键盘的远程软件，与本机物理输入在应用层无法可靠区分，必须以实测结果为准。

## 文件

- `CatKeyboardGuard.ps1`：主程序源码。
- `CatKeyboardGuard.exe`：带猫猫头图标的应用程序入口。
- `CatKeyboardGuard.cs`：应用程序入口源码。
- `Start-CatKeyboardGuard.vbs`：兼容启动器，优先启动应用程序入口。
- `assets/cat-head.ico`：窗口、系统托盘和开机启动项使用的猫猫头图标。

程序文件内嵌猫猫头图标，并为当前进程设置独立的 Windows 应用标识，任务栏不再使用 PowerShell 图标与分组。

如果要卸载，先在托盘菜单中退出程序，取消“开机自动启动”，然后删除本文件夹即可。
